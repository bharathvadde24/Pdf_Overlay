It loads a PDF file using pdf.js, checks if the file is valid, and extracts total pages and outline/bookmarks.

It progressively renders each page into a canvas and shows page thumbnails in a left sidebar.

It allows users to zoom in/out, scroll through pages, and automatically updates the current page indicator.

It supports pinch-to-zoom, Ctrl+mouse-wheel zoom, and smooth scrolling to any page from the sidebar.

The component displays a full-screen overlay viewer, shows loading states, allows downloading the file, and closes when clicking outside or pressing the close button.
